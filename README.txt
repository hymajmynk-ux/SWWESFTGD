مدرسة البابا أثناسيوس الرسولي — الموقع الأول

النسخة تستخدم الصورة التي أرسلها المستخدم كما هي:
saint-athanasius.jpg

الموجود:
- صفحة دخول Mobile First.
- اسم المستخدم: مينا
- كلمة المرور: 123456789
- الصورة المرسلة كخلفية Full Screen.
- حركة Zoom هادئة للخلفية.
- صفحة رئيسية بعد تسجيل الدخول.
- نقاط الحضور.
- سجل الحضور.
- كل المستخدمين يرون نفس الموقع.
- تسجيل الحضور يوم الخميس فقط.
- الحضور يفتح الخميس الساعة 9:00 مساءً.
- أيام الخميس القادمة ظاهرة، والمواعيد غير الحالية تظهر مقفولة بالأسود.
- لا يمكن تسجيل الحضور مرتين في نفس الخميس.
- البيانات التجريبية تحفظ محليًا في المتصفح.

إضافة مستخدم:
افتح script.js وعدّل قائمة USERS مثل:
{ username: "اسم", password: "كلمة_المرور" }

تنبيه:
هذا Prototype Front-end فقط. كلمات المرور موجودة داخل JavaScript، لذلك لا يعتبر نظام أمان حقيقيًا للإنتاج.


تحديث النسخة الثانية:
- اسم الموقع ظاهر داخل الصفحة: ✝ مدرسة البابا أثناسيوس الرسولي.
- إضافة رسالة ترحيب شبابية وكنسية بعد تسجيل الدخول.
- إضافة خانة "المجموع" 👥.
- المجموعة التجريبية تعتمد على حضور آخر أسبوعين.
- يظهر عدد الحضور في المجموعة.


تحديث النسخة الثالثة:
- تم تحويل "المجموع" إلى خانة ثالثة مستقلة بجانب النقاط وأيام السجل.
- كل تسجيل حضور ناجح يزيد المجموع +1.
- التسجيل يظهر في السجل بالتاريخ والوقت.
- مثال: 2 مرات حضور = المجموع 2، والنقاط 20 إذا كانت النقاط +10 لكل حضور.
